Abstract Analyzer

Un outil pour explorer de grands corpus de résumés scientifiques : détection automatique de thématiques et de structures latentes, sans étiquetage manuel. Généralisation, sous forme d'outil réutilisable, de l'approche développée pour le projet académique « From Medical Texts to Meaningful Patterns » mené à l'ENSAI sur des résumés biomédicaux.

Approche envisagée

Ingestion Import de résumés scientifiques (CSV, PDF, API type PubMed/arXiv)
Représentation Embeddings contextuels (SciBERT) capturant le sens des textes
Réduction & clustering UMAP + HDBSCAN, hyperparamètres réglés par optimisation bayésienne
Exploration Interface interactive pour visualiser et nommer les thèmes détectés
Objectif : transformer un pipeline de recherche ponctuel en outil réutilisable sur n'importe quel corpus d'abstracts, pas seulement le jeu de données biomédical d'origine.

Stack technique envisagée

Langage : Python · NLP : SciBERT (transformers) · ML : UMAP, HDBSCAN, optimisation bayésienne · Interface : application interactive (à définir)
