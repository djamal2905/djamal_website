En cours de développement

AELYN — Assistant IA vocal local

AELYN est un assistant personnel local, orchestrant un LLM auto-hébergé (Ollama) et une famille d'agents spécialisés — conversation vocale, email, sécurité (reconnaissance faciale), carrière — conçu pour tourner en continu sur un Raspberry Pi, sans dépendre d'un cloud externe pour le raisonnement ou la reconnaissance vocale. Projet personnel en cours d'écriture ; cette page présente l'architecture cible.

Architecture

Matériel embarqué

Raspberry Pi Micro, haut-parleur, caméra — device toujours allumé, en local

Entrée / Sortie vocale

Wake word « Éline » Écoute continue, activation façon Siri
STT — SpeechRecognition Voix → texte
TTS — Kokoro Texte → voix (espeak-ng, voix FR)

Orchestration

aelyn_conversation Routeur d'intentions, confirmation selon le niveau de risque, lecture/résumé/brouillon

Cœur & raisonnement

aelyn (core) Configuration (.env), client LLM
Ollama LLM local (ex. qwen3) — aucune donnée envoyée à l'extérieur

Agents spécialisés

aelyn_email Tri, brouillons, envoi validé manuellement (IMAP/SMTP)
aelyn_security Reconnaissance faciale (DeepFace/ArcFace) via la caméra du Pi
aelyn_career Profil, recherche RAG (embeddings + BM25), CV/candidatures
Choix d'architecture : chaque agent est un package indépendant dans un monorepo uv (workspace Python), avec ses propres dépendances — l'objectif est de pouvoir ajouter un nouvel agent (domotique, santé, etc.) sans toucher aux autres, et de garder le raisonnement et la synthèse vocale entièrement locaux pour la confidentialité.

Stack technique

Langage : Python (workspace uv) · LLM : Ollama (local) · Voix : SpeechRecognition, Kokoro (kokoro-onnx), espeak-ng · Vision : DeepFace, ArcFace · Recherche : sentence-transformers, BM25 (rank_bm25) · Matériel cible : Raspberry Pi
