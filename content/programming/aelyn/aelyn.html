AELYN, your personal assistant, everywhere

One AI, multiple devices, one home. AELYN orchestrates a self-hosted LLM (Ollama) and a family of specialised agents (voice conversation, email, security, career, home automation) split across two Raspberry Pi 4 (brain/orchestration on one side, vision & security on the other), with an optional PC for heavy compute, secure remote access via Tailscale, and mobile (React Native), web (React), and voice interfaces. No dependency on an external cloud for reasoning. Personal project still being written; this page presents the target architecture.

Architecture

User interfaces

Phone (React Native) Voice/text chat, notifications, remote control
PC (React) Dashboard, device control, file access
Voice (wake word / STT / TTS) Natural conversation, Siri-like activation

Remote access & local network

Internet + Tailscale (VPN) Secure access to the local network from anywhere, no port forwarding
Freebox Pop Local Wi-Fi / Ethernet network

Core (2 Raspberry Pi 4)

Raspberry Pi #1 (AELYN Core) • FastAPI / WebSocket API
• Orchestrator (intent routing)
• Ollama, lightweight quantized model (e.g. GGUF Q4)
• Memory / RAG (profile, history)
• Agents (email, career, home…)
• Authentication & security
• Database / files
Raspberry Pi #2 (Vision & Security) • YOLO, object detection
• Facial recognition
• Anti-spoofing / liveness
• Tracking / event detection
• Sends alerts to Pi #1
local network

Compute node (optional)

PC, heavy compute (Wake-on-LAN) • Ollama, non-quantized, more sophisticated models
• Document analysis
• Model training
• PyTorch / CUDA
Model strategy: on the Raspberry Pi, Ollama runs a lightweight quantized model (e.g. GGUF Q4/Q5) to stay fast on constrained hardware. If the PC is powered on and available on the network (Wake-on-LAN), the Pi #1 orchestrator delegates the request to a more sophisticated, non-quantized model there instead. Otherwise, everything keeps running locally on the Pi, with a more modest model.

Peripherals & connected home

TV / Freebox Pop Netflix, YouTube… remote control (HDMI-CEC)
Cameras Video feed, detection, alerts
Connected home Lights, plugs (via Home Assistant, optional)
Storage Files, documents, backups
Example scenario: "Put Netflix on the TV". You talk to AELYN (phone or PC) → Pi #1 parses the request → it controls the Freebox Pop on the local network → the TV turns on → Netflix launches.
Architecture choice: each agent is an independent package in a uv monorepo (Python workspace), with its own dependencies. The goal is to be able to add a new agent (home automation, health, etc.) without touching the others, and to keep reasoning and speech synthesis entirely local for privacy.

Tech stack

Backend: Python (uv workspace), FastAPI / WebSocket · LLM: Ollama, quantized models on the Pi, full models on the PC when available · Voice: SpeechRecognition, Kokoro (kokoro-onnx), espeak-ng · Vision: YOLO, DeepFace, ArcFace (anti-spoofing) · Search: sentence-transformers, BM25 (rank_bm25) · Interfaces: React Native (mobile), React (web) · Network: Tailscale (VPN), Freebox Pop · Home automation: Home Assistant (optional) · Target hardware: 2 × Raspberry Pi 4, optional PC (GPU/CUDA)
