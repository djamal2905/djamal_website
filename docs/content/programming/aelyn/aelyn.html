En cours de développement

AELYN, ton assistant personnel, partout

Une seule IA, plusieurs appareils, une seule maison. AELYN orchestre un LLM auto-hébergé (Ollama) et une famille d'agents spécialisés (conversation vocale, email, sécurité, carrière, domotique) répartis sur deux Raspberry Pi 4 (cerveau/orchestration d'un côté, vision & sécurité de l'autre), avec un PC optionnel pour les calculs lourds, un accès distant sécurisé via Tailscale, et des interfaces mobile (React Native), web (React) et vocale. Aucune dépendance à un cloud externe pour le raisonnement. Projet personnel en cours d'écriture ; cette page présente l'architecture cible.

Architecture

Interfaces utilisateur

Téléphone (React Native) Chat vocal/texte, notifications, contrôle à distance
PC (React) Dashboard, contrôle des appareils, accès aux fichiers
Voix (wake word / STT / TTS) Conversation naturelle, activation façon Siri

Accès distant & réseau local

Internet + Tailscale (VPN) Accès sécurisé au réseau local depuis n'importe où, sans ouverture de port
Freebox Pop Réseau local Wi-Fi / Ethernet

Cœur (2 Raspberry Pi 4)

Raspberry Pi #1 (AELYN Core) • API FastAPI / WebSocket
• Orchestrateur (routage d'intentions)
• Ollama, LLM local léger
• Mémoire / RAG (profil, historique)
• Agents (email, carrière, maison…)
• Authentification & sécurité
• Base de données / fichiers
Raspberry Pi #2 (Vision & Sécurité) • YOLO, détection d'objets
• Reconnaissance faciale
• Anti-spoofing / liveness
• Tracking / détection d'événements
• Envoi des alertes au Pi #1
réseau local

Nœud de calcul (optionnel)

PC, gros calculs (Wake-on-LAN) • Ollama, gros modèles
• Analyse de documents
• Entraînement de modèles
• PyTorch / CUDA

Périphériques & maison connectée

TV / Freebox Pop Netflix, YouTube… contrôle à distance (HDMI-CEC)
Caméras Flux vidéo, détection, alertes
Maison connectée Éclairage, prises (via Home Assistant, optionnel)
Stockage Fichiers, documents, sauvegardes
Exemple de scénario : « Mets Netflix sur la télé ». Tu parles à AELYN (téléphone ou PC) → le Pi #1 analyse la demande → il contrôle la Freebox Pop sur le réseau local → la TV s'allume → Netflix se lance.
Choix d'architecture : chaque agent est un package indépendant dans un monorepo uv (workspace Python), avec ses propres dépendances. L'objectif est de pouvoir ajouter un nouvel agent (domotique, santé, etc.) sans toucher aux autres, et de garder le raisonnement et la synthèse vocale entièrement locaux pour la confidentialité.

Stack technique

Backend : Python (workspace uv), FastAPI / WebSocket · LLM : Ollama (local) · Voix : SpeechRecognition, Kokoro (kokoro-onnx), espeak-ng · Vision : YOLO, DeepFace, ArcFace (anti-spoofing) · Recherche : sentence-transformers, BM25 (rank_bm25) · Interfaces : React Native (mobile), React (web) · Réseau : Tailscale (VPN), Freebox Pop · Domotique : Home Assistant (optionnel) · Matériel cible : 2 × Raspberry Pi 4, PC optionnel (GPU/CUDA)
